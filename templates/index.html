🔍 What This Platform Is

This is a live Network Operations Center dashboard for a simulated city-wide fiber (GPON) network — modeled on Delhi, across 5 regions and 25 zones. The network is structured as a real four-tier hierarchy: Core Router → Regional POP → Zone OLT → Passive Splitter → Customer ONU, currently representing {{ total_network_users }} subscriber connections across {{ devices|length }} devices.

Click to read more →

⚙️ How It Works

A background monitor process reads a simulated network-state file every 5 seconds and reports every device's status to the backend in a single batched request — not one call per device — so the whole network is checked well within each polling cycle even at this scale. Tickets open and resolve automatically, and the dashboard refreshes live in the background with zero page reloads.

Key Capabilities

📡

Live Device Monitoring

Every Core, POP, OLT, Splitter, and ONU tracked in real time, filterable by device type and by zone.

🚨

Automatic Ticketing

A ticket opens the moment a device goes offline and auto-resolves the moment it recovers — no manual entry.

🎯

Real Blast-Radius Analysis

Subscriber impact is calculated by walking the actual fiber tree, not a formula — so the number is always correct, including cascading failures.

📝

Editable Incident Workflow

Each ticket supports an ETR plus three separate notes — for the partner, the internal team, and the public — saved directly to the record.

🔎

PON / Zone Filtering

Instantly narrow Devices, Alerts, or Tickets down to a single zone or a single device type — OLTs, splitters (PON), or customer ONUs.

📊

Historical Analytics

Subscriber online/affected counts are logged over time, so outages and recoveries show up as real dips and recoveries on the chart, not a static snapshot.

💡 Why This Approach

A status board that only shows red or green isn't enough to run a network on — the questions that actually matter during an incident are "how many customers does this affect" and "what's already being done about it." This dashboard treats both as first-class data.
